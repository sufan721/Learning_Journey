外键让两张表之间建立联系，确保数据的一致性和完整性

## 1. 建表时加外键
```sql
create table 表名 (
	字段名  数据类型
	...
	constraint 外键名 foreign key (外键列)  references 父表名(被引用列)
);
```

## 2. 已存在表加外键
```sql
alter table alter 表名 add constraint 外键名称 foreign key 外键字段名 references 主表(主表列名);
```

## 3. 删除外键

```sql
alter table alter 表名
drop foreign key foreign 外键名;
```

### 四、核心总结
1. 核心关键词：FOREIGN KEY (foreign key)、REFERENCES (references)、CONSTRAINT (constraint)
2. 外键行为：RESTRICT (restrict)、CASCADE (cascade)、SET NULL (set null) 是高频选项
