### **IF(if)**(value, t, f)
```
如果value为真，则返回t，否则返回f
```
### **IFNULL(ifnull)**(value1, value2)
```
如果value1不为空，返回value1，否则返回value2
```
### **CASE WHEN(case when)**​ [val1] THEN [res1] ... ELSE [default] END
```
如果val1为真，返回res1，... 否则返回default默认值
```
### **CASE(case)**​ [expr] WHEN [val1] THEN [res1] ... ELSE [default] END
```
如果expr的值等于val1，返回res1，... 否则返回default默认值
```
