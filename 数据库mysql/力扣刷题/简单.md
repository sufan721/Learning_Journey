[175. 组合两个表 - 力扣（LeetCode）](https://leetcode.cn/problems/combine-two-tables/description/)
##### 思考方向：
直接多表查询就好，条件为 personId相同 ,而且要有空，需要连接查询
#####  代码(错)：
```mysql、
select a.firstName , a.lastName , b.city ,  b.state
from Person a,Address b
where a.personId=b.personId
```
##### 代码(正确)：
```mysql
select firstName , lastName , city ,  state
from Person left join Address 
on Person.personId=Address.personId 
```
- **注意null为preson ，所以是左连接**

[181. 超过经理收入的员工 - 力扣（LeetCode）](https://leetcode.cn/problems/employees-earning-more-than-their-managers/)
##### 思考方向：
很明显，你需要，自己查自己 -> 自连接 条件就是managerId =  id and salary 更大
#####  代码：
```mysql
select a.name as Employee
from Employee a ,Employee b
where a.managerId = b.id 
	and a.salary >b.salary
```

[182. 查找重复的电子邮箱 - 力扣（LeetCode）](https://leetcode.cn/problems/duplicate-emails/)
##### 思考方向：
很明显 ，如果一个邮箱的数量大于1 -> 重复 ，直接分组看数量就好
#####  代码：
```mysql
select email
from Person
group by email
having count(1) > 1
```

[183. 从不订购的客户 - 力扣（LeetCode）](https://leetcode.cn/problems/customers-who-never-order/)
##### 思考方向：
没啥话说， 多表查询，Customers的 name不在Orders的customerId里面
#####  代码：
```mysql
select name as Customers
from Customers
where id not in (
	select customerId 
	from Orders
)
```

[196. 删除重复的电子邮箱 - 力扣（LeetCode）](https://leetcode.cn/problems/delete-duplicate-emails/)
##### 思考方向：
还是查询那样，先查询，在删除但和查询不一样的是，需要留一个 那么，应该自连接 后删除id更大的那个
#####  代码：
```mysql
delete a 
from Person a, Person b
where a.email = b.email and a.id > b.id 
```
##### 另一种解法更快：
###### 思考方向：
对于每一个email而言，我们只需留住最小的id就好，单个的最小id就是自己，其他的删掉
######  代码：
```mysql
delete
from Person
where id not in (
    select min_id from (
        select min(id) as min_id
        from Person
        group by email
    ) as temp
);
```
