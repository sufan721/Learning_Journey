### [175. 组合两个表 - 力扣（LeetCode）](https://leetcode.cn/problems/combine-two-tables/description/)
#### 思考方向：
直接多表查询就好，条件为 personId相同 ,而且要有空，需要连接查询
#####  代码(错)：
```sql
select a.firstName , a.lastName , b.city ,  b.state
from Person a,Address b
where a.personId=b.personId
```
##### 代码(正确)：
```sql
select firstName , lastName , city ,  state
from Person left join Address 
on Person.personId=Address.personId 
```
- **注意null为preson ，所以是左连接**

### [196. 删除重复的电子邮箱 - 力扣（LeetCode）](https://leetcode.cn/problems/delete-duplicate-emails/)
#### 思考方向：
还是查询那样，先查询，在删除但和查询不一样的是，需要留一个 那么，应该自连接 后删除id更大的那个
#####  代码：
```sql
delete a 
from Person a, Person b
where a.email = b.email and a.id > b.id 
```
##### 另一种解法更快：
##### 思考方向：
对于每一个email而言，我们只需留住最小的id就好，单个的最小id就是自己，其他的删掉
######  代码：
```sql
delete
from Person
where id not in (
    select min_id from (
        select min(id) as min_id
        from Person
        group by email
    ) as temp
);
```

### [577. 员工奖金 - 力扣（LeetCode）](https://leetcode.cn/problems/employee-bonus/)
#### 思考方向：
还是链接条件和查询条件的问题**on：是连接的条件**    **where：是查询的条件** 
连接的条件为id相同，查询条件为**b的工资为小于1000**或为**null**
#####  代码：
```sql
select e.name ,a.bonus 
from Employee  e 
left join Bonus a 
on (a.empId=e.empId )
where bonus < 1000 or bonus is null 
```

### [619. 只出现一次的最大数字 - 力扣（LeetCode）](https://leetcode.cn/problems/biggest-single-number/)
#### 思考方向：
首先搜索只出现一次的数字 -> 对数字进行分组，然后求count = 1 
然后在返回的子表里查询最大值
#####  代码：
```sql

select max(num) as num 
from (
	select num 
	from MyNumbers 
	group by num 
	having count(0) =1 
) a
```
