### [184. 部门工资最高的员工 - 力扣（LeetCode）](https://leetcode.cn/problems/department-highest-salary/)

#### 思考方向：
没什么好说的，基本还是之前的思考方式
#####  代码：
```mysql
select a.name  Department , b.name Employee, b.salary
from Department a , Employee  b
where (
    a.id = b.Departmentid
    and ( b.salary, b.Departmentid)in (
        select max(salary) , Departmentid
        from Employee
        group by Departmentid
    )
)
```

### [570. 至少有5名直接下属的经理 - 力扣（LeetCode）](https://leetcode.cn/problems/managers-with-at-least-5-direct-reports/)

#### 思考方向：
先创建子表，在主表里查询子表的内容。 子表的内容为管理者的ID，分组为管理者条件为数量大于4(因为最低为5) 

#####  代码：
```sql
select a.name 
from Employee  a
where (
    a.id in (
        select managerId 
        from Employee  
        group by  managerId    
        having count(1) > 4
    )
)
```

### [1393. 股票的资本损益 - 力扣（LeetCode）](https://leetcode.cn/problems/capital-gainloss/description/)

#### 思考方向：

#####  代码：
```sql
select stock_name , sum(
    case
        when operation  ='Buy' then -price
        else price
    end
) as capital_gain_loss
from Stocks
group by stock_name;
```

### [585. 2016年的投资 - 力扣（LeetCode）](https://leetcode.cn/problems/investments-in-2016/submissions/716693508/)

#### 思考方向：
分组有点麻烦，而且还要注意四舍五入 ， 还有必须两个分支分组，不能在主分支分组
#####  代码：
```sql
select round(sum(tiv_2016),2) as tiv_2016
from Insurance  
where (lat, lon) in (
    select lat ,lon 
    from Insurance 
    group by lat , lon 
    having count(1) = 1 
) and  
tiv_2015 in (
    select tiv_2015
    from Insurance 
    group by  tiv_2015 
    having count(1) > 1 
)
```

### [602. 好友申请 II ：谁有最多的好友 - 力扣（LeetCode）](https://leetcode.cn/problems/friend-requests-ii-who-has-the-most-friends/)

#### 思考方向：
首先最多的好友，最后的排序desc，然后就是查询好友了，两个表联合然后(count)一下
#####  代码：
```sql
select id, count(*) num
from (
  select requester_id id from RequestAccepted
  union all
  select accepter_id id from RequestAccepted
) t1
group by id
order by num desc
limit 1
```

### [626. 换座位 - 力扣（LeetCode）](https://leetcode.cn/problems/exchange-seats/submissions/734093585/)

#### 思考方向：
这道题目实际上比较简单，因为逻辑可以清晰的梳理出来并直接实现：
查询id和student
- 若id是偶数，减1
- 若id是奇数，加1
主要问题在于当总数为奇数时，最后一个id应保持不变，加1会导致空出一位。
解决此问题并不复杂：我们找到最后一位，让它保持不变就可以了

#####  代码：
```sql
select 
    if(id%2=0,
        id-1,
        if(id=(select count(distinct id) from seat),
            id,
            id+1)) 
    as id,student 
from seat 
order by id;
```
