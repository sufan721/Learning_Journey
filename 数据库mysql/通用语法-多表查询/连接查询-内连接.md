###### 隐式内连接：
```mysql
select 字段列表 from 表1 ， 表2 where 条件 ...;
```
###### 显示内连接：
```mysql
select 字段列表 from 表1 [inner] join 表2 on 连接条件 ...;
```
**内连接查询的是两张表的交集部分**

```mysql
select
	case
		when count(*) = 0 then null
		else max(num)
	end as num
from MyNumbers
where num in (
	select num
	from MyNumbers
	group by(num)
	having count(num) =1
);
```
