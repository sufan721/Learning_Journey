在SQL语句中嵌套select语句，称为==嵌套查询==，也就是子查询
根据子查询结果的不同，分为：
#### 标量子查询：
子查询结果为==单个值==
```mysql
select * from t1 where c1 = (select c1 from t2);
```
#### 列子查询：
子查询结果为==一列==
###### 操作符
| in     | 在指定的集合          |
| ------ | --------------- |
| not in | 不在指定的集合范围内      |
| any    | 子集返回列表中满足任意一个即可 |
| some   | 和any相同          |
| all    | 子集返回列表中必须全部满足即可 |
```mysql
select * from t1 where c1 in (select c2 from t2);
```
#### 行子查询：
子查询结果为==一行==

#### 表子查询：
子查询结果为==多行多列==


位置可以为：==where之后==，==from之后==， ==select之后==
