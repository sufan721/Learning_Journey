### 基本语法:
```
[ conditicn ]
(注意condition前后要有空格)#非空返回true，可使用$?验证(0为true，>1为false)
```


### 常用判断条件

| 判断类型        | 符号/选项 | 说明                           |
| ----------- | ----- | ---------------------------- |
| **字符串比较**​  | `=`   | 判断两个字符串是否相等                  |
| **整数比较**​   | `-lt` | 小于 (less than)               |
|             | `-le` | 小于等于 (less than or equal)    |
|             | `-eq` | 等于 (equal)                   |
|             | `-gt` | 大于 (greater than)            |
|             | `-ge` | 大于等于 (greater than or equal) |
|             | `-ne` | 不等于 (not equal)              |
| **文件权限判断**​ | `-r`  | 检查文件是否有读权限                   |
|             | `-w`  | 检查文件是否有写权限                   |
|             | `-x`  | 检查文件是否有执行权限                  |
| **文件类型判断**​ | `-f`  | 检查文件是否存在且是一个常规文件             |
|             | `-e`  | 检查文件或目录是否存在                  |
|             | `-d`  | 检查是否存在且是一个目录                 |
