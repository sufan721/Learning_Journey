# Docker 基础命令

Docker 和 Git 一样分为**镜像仓库**和**本地镜像**，核心就三件事：镜像怎么来、容器怎么管、数据怎么流。

---

## 核心概念速览

| 概念 | 类比 | 说明 |
|------|------|------|
| **镜像 (Image)** | 类 (Class) | 容器的模板，只读 |
| **容器 (Container)** | 实例 (Object) | 镜像的运行实例，可读可写 |
| **仓库 (Registry)** | GitHub | 存储和分发镜像的地方（Docker Hub） |
| **Dockerfile** | 源码 | 用来自己构建镜像的脚本 |
| **数据卷 (Volume)** | 外挂硬盘 | 持久化数据，容器删了数据还在 |

---

## 一、镜像相关命令

| 命令 | 说明 | 常用参数 |
|------|------|----------|
| `docker pull 镜像名:版本` | 从仓库拉取镜像 | 不写版本默认 `:latest` |
| `docker images` | 查看本地镜像列表 | `-q` 只显示镜像ID |
| `docker rmi 镜像ID/名` | 删除本地镜像 | `-f` 强制删除 |
| `docker build -t 镜像名:版本 .` | 从 Dockerfile 构建镜像 | `-t` 指定标签, `-f` 指定Dockerfile路径 |
| `docker save -o 文件名.tar 镜像名` | 导出镜像为压缩文件 | `-o` 输出文件 |
| `docker load -i 文件名.tar` | 从压缩文件加载镜像 | `-i` 输入文件 |
| `docker push 镜像名:版本` | 推送镜像到仓库 | 需先 `docker login` |
| `docker tag 原镜像 新镜像:版本` | 给镜像打标签 | 推送前常用于加仓库前缀 |
| `docker search 关键词` | 搜索 Docker Hub 镜像 | `--limit 25` 限制返回数量 |
| `docker history 镜像名` | 查看镜像构建历史层 | 看每一层大小 |
| `docker image prune` | 删除未被使用的镜像 | `-a` 删除所有未使用的 |

### 示例

```bash
# 拉取指定版本
docker pull nginx:1.25
docker pull mysql:8.0

# 查看镜像
docker images

# 删除镜像（先确保没有容器在用）
docker rmi nginx:1.25

# 从 Dockerfile 构建
docker build -t my-app:v1 .

# 导出 / 导入（离线迁移）
docker save -o nginx.tar nginx:latest
docker load -i nginx.tar

# 打标签准备推送
docker tag my-app:v1 docker.io/username/my-app:v1
docker push docker.io/username/my-app:v1
```

## 二、容器相关命令

### docker run — 创建并运行新容器

```
docker run [参数] 镜像名 [命令]
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `-d` | 后台运行（detach） | `-d` |
| `--name` | 给容器命名 | `--name my-nginx` |
| `-p` | 端口映射 `主机端口:容器端口` | `-p 8080:80` |
| `-e` | 设置环境变量 | `-e MYSQL_ROOT_PASSWORD=123` |
| `-v` | 数据卷挂载 | `-v html:/usr/share/nginx/html` |
| `--restart` | 重启策略 | `--restart always`（开机自启） |
| `-it` | 交互模式 + 分配终端 | `-it` |
| `--rm` | 容器停止后自动删除 | `--rm` |
| `--network` | 指定网络 | `--network my-net` |
| `-m` | 限制内存 | `-m 512m` |

### 容器生命周期命令

| 命令 | 说明 |
|------|------|
| `docker run` | 创建并启动新容器 |
| `docker start 容器` | 启动已存在的**停止状态**容器 |
| `docker stop 容器` | 优雅停止（SIGTERM → 等待 → SIGKILL） |
| `docker restart 容器` | 重启容器 |
| `docker pause 容器` | 暂停容器进程 |
| `docker unpause 容器` | 恢复暂停的容器 |
| `docker kill 容器` | 立即强制停止 |
| `docker rm 容器` | 删除已停止的容器（`-f` 强制删除运行中的） |

### 容器信息查看

| 命令 | 说明 |
|------|------|
| `docker ps` | 查看**运行中**的容器 |
| `docker ps -a` | 查看**所有**容器（含已停止） |
| `docker logs 容器` | 查看容器日志（`-f` 实时跟踪, `--tail 100` 最后100行） |
| `docker inspect 容器` | 查看容器完整信息（JSON格式，含IP、挂载、网络等） |
| `docker top 容器` | 查看容器内运行的进程 |
| `docker stats` | 实时查看容器资源使用（CPU / 内存 / 网络） |
| `docker port 容器` | 查看端口映射 |

### 与容器交互

| 命令 | 说明 |
|------|------|
| `docker exec -it 容器 bash` | 进入运行中的容器 |
| `docker cp 主机路径 容器:容器路径` | 从主机复制文件到容器 |
| `docker cp 容器:容器路径 主机路径` | 从容器复制文件到主机 |
| `docker attach 容器` | 连接到容器的主进程（不常用） |
| `docker commit 容器 新镜像名` | 把容器的修改保存为新镜像 |

### 示例

```bash
# 创建并后台运行 nginx
docker run -d --name nginx -p 80:80 nginx

# 交互模式运行 Ubuntu，退出后自动删除
docker run -it --rm --name temp-ubuntu ubuntu bash

# 运行 MySQL 并持久化数据
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root123 \
  -v mysql-data:/var/lib/mysql \
  --restart always \
  mysql:8.0

# 查看运行中的容器
docker ps

# 查看所有容器（含已停止）
docker ps -a

# 实时查看日志
docker logs -f nginx

# 进入容器内部
docker exec -it nginx bash

# 查看容器详细信息（IP、挂载路径等）
docker inspect nginx

# 从容器复制文件出来
docker cp nginx:/etc/nginx/nginx.conf ./nginx.conf

# 从主机复制文件进去
docker cp ./index.html nginx:/usr/share/nginx/html/

# 优雅停止
docker stop nginx

# 重新启动
docker start nginx

# 删除容器
docker rm nginx
```

## 三、系统管理命令

| 命令 | 说明 |
|------|------|
| `docker system df` | 查看 Docker 磁盘占用 |
| `docker system prune` | 清理未使用的容器、网络、镜像（**谨慎**，会删很多东西） |
| `docker system prune -a` | 更彻底的清理（包含所有未使用的镜像） |
| `docker info` | 查看 Docker 系统信息 |
| `docker version` | 查看 Docker 版本 |
| `docker login` | 登录镜像仓库 |

## 五、测试案例

### 需求：
- 在 Docker Hub 中搜索 nginx 镜像，并查看镜像名称
- 拉取 nginx 镜像
- 查看镜像列表
- 创建并运行 Nginx 容器
- 查看容器
- 进入 Nginx 容器，修改网页内容
- 查看容器日志
- 将容器内的网页复制到宿主机
- 停止容器
- 再次启动容器，验证数据还在
- 删除容器

### 实操

```bash
# 1. 搜索 nginx 镜像
docker search nginx --limit 10

# 2. 拉取镜像（不写版本默认 latest）
docker pull nginx

# 3. 查看本地镜像列表
docker images

# 4. 创建并运行容器
docker run -d --name my-nginx -p 80:80 nginx

# 5. 查看运行中的容器
docker ps

# 6. 进入容器
docker exec -it my-nginx bash
# 在容器内：
echo "<h1>Hello Docker!</h1>" > /usr/share/nginx/html/index.html
exit

# 7. 查看容器日志
docker logs my-nginx --tail 20

# 8. 把容器内的文件复制到宿主机
docker cp my-nginx:/usr/share/nginx/html/index.html ./index.html

# 9. 停止容器
docker stop my-nginx

# 10. 重新启动，验证网页内容还在
docker start my-nginx
curl http://localhost
# 输出：<h1>Hello Docker!</h1>

# 11. 清理：停止并删除容器
docker stop my-nginx
docker rm my-nginx

# 12. 可选：删除镜像
docker rmi nginx
```

## 六、常见操作组合

### 停止并删除所有容器
```bash
docker stop $(docker ps -aq)
docker rm $(docker ps -aq)
```

### 删除所有未使用的镜像
```bash
docker image prune -a
```

### 查看容器资源占用
```bash
docker stats
```

### 进入容器快速排错
```bash
# 如果容器内没有 bash，用 sh
docker exec -it 容器名 sh

# 查看容器内文件结构
docker exec 容器名 ls -la /app
```

### 查看容器最后的日志
```bash
docker logs --tail 50 -f 容器名
```

## 注意事项

1. **区分 `docker run` 和 `docker start`**：`run` 是从镜像创建新容器，`start` 是启动已有的停止容器。每次 `run` 都会创建新容器。
2. **`latest` 标签陷阱**：`latest` 只是默认标签名，不代表真的是最新版。生产环境永远指定具体版本号（如 `nginx:1.25`）。
3. **容器退出后数据还在**：容器停止后数据不会丢，只有执行 `docker rm` 才会清理容器层的数据。但数据卷（volume）里的数据即使 `rm` 也不会丢。
4. **退出容器不要用 `exit` 关掉了**：用 `Ctrl+P + Ctrl+Q` 可以退出终端但不断开容器（detach），`exit` 会停止容器主进程。
5. **端口冲突**：如果宿主机端口已被占用，换个端口号即可，比如 `-p 8080:80`。
