在上一章中，我们说过有**仓库**用于**保存我们的文件和进度**，那么这个仓库如果只是本地的话，那么不利于我们的使用，所以--**云端仓库**自然而然就诞生了 

---

## 远程备份
首先既然是远程备份，那么你需要现在github上创建一个空的仓库，然后
#### 1. 远程连接
```
git remote add origin <远程仓库地址.git>
```
- `origin` 是给远程仓库起的代号，以后提到它就代表云端。
#### 2. 第一次推送
```
git push -u origin main
```
`-u` 会建立连接，以后你只需要输入 `git push`，Git 就能自动往这儿传。
#### 3. 从云端同步
```
git pull [远程仓库名] [分支名]
```
- `[远程仓库名]` 通常是 `origin`，是默认的远程仓库名。
- `[分支名]` 是你要合并的远程分支，比如 `main` 或 `master`。
