如果你想写一篇“实验性”的长文，又不确定最后要不要保留，分支就是你的“平行宇宙”。

---

1. **创建并切换到新分支**：
    ```
    git checkout -b feature-new-idea
    ```
    
2. **查看当前在哪个分支**：
    
    ```
    git branch
    ```
    
3. **合并回主分支**： 先切回主干：`git checkout main` 再合并：`git merge feature-new-idea`
    
4. **删掉没用的实验分支**：
5. ```
    git branch -d feature-new-idea
    ```
