在使用之前请完成[[配置git]]
这一章的内容属于基础中的基础，**必须会**

---
在使用git之前，需要先知道git的核心三个区域：
1. 工作区：正在编辑/使用的文件夹
2. 暂存区：挑选那些修改过的文件准备提交
3. 本地仓库：永久存储的地方
---
## 第一步：初始化
```
git init
```
---

## 第二步：保存修改 (Add & Commit)

这是最日常的操作，相当于给笔记拍“快照”。

- **追踪文件**（放入暂存区）：
    ```
    git add <文件名>   # 添加指定文件
    git add .         # 添加当前目录下所有修改
    ```
- **正式存档**（存入本地仓库）：
    ```
    git commit -m "你的提交记录说明"
    ```
---

## 第三步：查看状态与差异
如果你忘了改了什么，或者想确认有没有存好：
- **查看当前状态**：
    ```
    git status
    ```
- **查看具体改了哪几行**（在 add 之前使用）：
    ```
    git diff
    ```
---

## 第四步：回顾历史 (Log)
想看看自己过去都干了什么？
- **查看简洁历史**：
    ```
    git log --oneline
    ```
- **查看详细历史**（含作者、日期）：
    ```
    git log   #建议直接用这个
    ```

---

## 第五步：穿越时空 (Checkout/Reset)

这是 Git 最强大的地方：**后悔药**。

- **撤销工作区的修改**（回到上一次 commit 的状态）：
    ```
    git checkout -- <文件名>
    ```
- **回退到某个版本**：
    ```
    git reset --hard <版本哈希值>
    ```
    > **警告**：`--hard` 会抹掉未保存的修改，使用前请三思！
