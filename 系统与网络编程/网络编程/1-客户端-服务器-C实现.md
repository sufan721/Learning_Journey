## 服务器完整流程：
```c++
socket()  #创建用于通信的套接字
bind()    #绑定ip和地址
listen()  #将模式改为监听
accept()  #接收客户端
read()/recv() #接收数据
write()/send()  #发送数据
close() #关闭
```

### socke套接字函数：
```c++
int socket(int domain, int type, int protocol);
```
##### 1️⃣ domain —— 协议族
```
| AF_INET  | IPv4   
| AF_INET6 | IPv6   
| AF_UNIX  | 本地进程通信 
```
---

##### 2️⃣ type —— 套接字类型
```
| SOCK_STREAM | TCP（可靠）
| SOCK_DGRAM  | UDP（不可靠） 
```
---

##### 3️⃣protocol —— 协议
系统自动选择-> `0`

### bind —— 绑定地址
```
int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
```
作用：
> 把 socket 绑定到 IP + 端口

示例：
```
struct sockaddr_in serv;

serv.sin_family = AF_INET;  #ipv4
serv.sin_port = htons(8080); #端口
serv.sin_addr.s_addr = INADDR_ANY;  #ip为扫描到的ip

bind(sockfd, (struct sockaddr*)&serv, sizeof(serv));

```
### listen —— 监听
```
int listen(int sockfd, int backlog);
```
作用：
> 把 socket 变成监听 socket

示例：
```
listen(sockfd, 5);
```
- 5 = 最大排队连接数

---

###  accept —— 接收客户端

```
int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
```

作用：
> 等待客户端连接

成功返回：
>新的 socket（专门和客户端通信）

---

###  recv / read —— 接收数据

```
recv(connfd, buf, sizeof(buf), 0);
```
---

###  send / write —— 发送数据

```
send(connfd, "hello", 5, 0);
```

## 常用头文件：
  
```c
<sys/types.h>：定义数据类型。
<sys/socket.h>：提供 socket 函数及数据结构。
<netinet/in.h>：定义数据结构 _sockaddr_in_。
<arpa/inet.h>：提供 IP 地址转换函数。
<netdb.h>：提供设置及获取域名的函数。
<sys/ioctl.h>：提供对 I/O 控制的函数。
<unistd.h>：提供通用的文件、目录、程序及进程操作的函数。
<errno.h>：提供错误号 _errno_ 的定义，用于错误处理。
<fcntl.h>：提供对文件控制的函数。
<time.h>：提供有关时间的函数。
```
